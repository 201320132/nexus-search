# Nexus Search

A premium dark-mode search experience inspired by the feel of modern AI search products.

## Features
- Dark glassmorphism interface
- Custom logo and visual identity
- AI summary panel
- Search filters and suggestions
- Responsive layout
- Modern search result cards

## Run locally

```bash
npm install
npm run dev
```

Then visit:

```text
http://localhost:3000
```

## Production build

```bash
npm run build
```

## Notes
This is a polished front-end prototype designed to mimic the feel of a real AI-driven search experience while staying easy to run locally.
